# ranking: top N / tier list

**Hợp với:** "Top 3/5 tool làm video miễn phí", so nhiều tool một lúc, tổng hợp, xếp hạng S/A/B/C.

**Bảng màu:** `gold` (nền #0e0e10, hạng 1 #ffd700, 2 #c0c0c0, 3 #cd7f32, mặc định) · `neon` (nền #07070d, hạng màu hồng/xanh/tím neon) · `tier` (dải S đỏ #ff7f7f, A cam #ffbf7f, B vàng #ffdf7f, C xanh #7fff7f).

**Bố cục:** A-roll full khung ở hook và giữa các hạng. Mỗi hạng: **số khổng lồ** (500px, viền chữ accent, rỗng ruột) đập xuống,
card tool (logo/ảnh chụp thật + tên + 1 dòng điểm mạnh + giá "Miễn phí / $10/th") trượt lên chiếm 60% giữa.
Góc trên phải luôn có **bảng xếp hạng mini** điền dần các tool đã nói.

**Thành phần:**
- Đếm ngược N → 1, mỗi số kèm tiếng trống "boom".
- **Thanh điểm** (chất lượng / tốc độ / giá) chạy từ 0 tới điểm, số đếm cùng.
- **Tier list:** kéo logo vào hàng S/A/B/C, logo bay theo đường cong và nảy.
- **Hạng 1:** confetti + viền vàng nhấp nháy + chữ "TOP 1" nghiêng.
- Kết: cả bảng xếp hạng hiện full, CTA "lưu lại để dùng".

**Chuyển cảnh:** whip-pan ngang (mờ chuyển động) giữa các hạng. **Nhạc:** hype/trap, đẩy dần cường độ tới hạng 1.
