# retro: Windows 95 / máy tính đời cũ

**Hợp với:** tool vui, meme, so sánh "ngày xưa vs bây giờ", tool AI làm thay việc nhàm chán, kênh hài hước.

**Bảng màu:** `win95` (nền teal #008080, cửa sổ #c0c0c0, thanh tiêu đề #000080, mặc định) · `mac` (nền kẻ sọc #ddd, đen trắng 1-bit) · `vapor` (nền gradient #ff71ce→#01cdfe, cửa sổ #c0c0c0).
**Font:** chữ pixel cho tiêu đề cửa sổ (VT323 / Press Start 2P, chỉ dùng cho chữ không dấu hoặc kiểm tra dấu), nội dung tiếng Việt dùng Be Vietnam Pro 700.

**Bố cục:** A-roll nằm **trong một cửa sổ** "webcam.exe" (viền nổi 3D), cửa sổ khác bật lên chồng lên nhau, kéo thả, thu nhỏ.
Thanh taskbar + nút Start + đồng hồ ở đáy: chỉ là trang trí (vùng y > 1500 bị tên kênh/mô tả TikTok che), không đặt chữ cần đọc trên taskbar.

**Thành phần:**
- **Hộp thoại lỗi** (⚠/❌ + nút OK) bật liên tục chồng lên nhau cho câu "vấn đề"; bấm OK là tất cả biến mất.
- **Cửa sổ tool** (ảnh chụp tool thật nhét vào khung Win95), thanh tiến trình xanh khối.
- **Con trỏ mũi tên trắng** di chuyển, double-click, icon desktop.
- **Cài đặt:** "Đang cài đặt [tên tool]…" thanh khối chạy, xong → "Cài đặt thành công" + fanfare.
- **Màn hình xanh** (BSOD) làm hook hoặc "tool cũ chết rồi".

**Chuyển cảnh:** cửa sổ mở/đóng có hiệu ứng khung dây (outline phóng to), tiếng click chuột và âm khởi động. **Nhạc:** chiptune 8-bit.
