Chuẩn hoá giọng Clip nói bị bé: nâng về mức chuẩn mà không vỡ tiếng. Hình giữ nguyên, chỉ đổi tiếng.
Kéo thả clip vào đây mp4, mov, m4v hoặc file tiếng wav, m4a, mp3. Nhiều file một lúc được. Dùng file thu gốc, chưa kéo âm lượng.
Kéo thanh âm lượng trong CapCut chỉ nhân cả đoạn lên: đỉnh chạm trần thì vỡ, giọng vẫn bé. Ở đây đỉnh được ghìm ở -1.5 dB rồi mới nâng. Bỏ file kết quả vào CapCut và để âm lượng clip ở mức gốc.
